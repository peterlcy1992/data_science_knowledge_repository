## 🔎 Deep dive: When Covariates Mask Pre-Trends

*arXiv econ.EM (Parush Arora, Ashoka University) · experimentation-causal (Core DS) · Core DS pick (rotation: only 1 of the last 4 deep dives was Core DS, so Core DS was due) · novelty 4/5 · full text read*

**The problem.** Honest difference-in-differences methods (Rambachan and Roth) bound how far parallel trends may fail after treatment by how far it failed before, using placebo estimates; the breakdown value is the largest multiple M at which the confidence set still excludes zero. When the design adjusts for covariates, the placebos are adjusted too.

**The result.** The adjusted benchmark is valid only if covariates are measured before the earliest placebo window. A covariate measured later already reflects shocks to the outcome in the placebo period, so each adjusted placebo splits into a trend term plus a shock term. In the usual case the shocks pull placebos down relative to the post-treatment trend: pre-trends look flatter than they are and the honest confidence sets are too narrow. In a linear design the shock terms can cancel the trend entirely so no finite M covers the effect. The effect estimate itself can be unaffected, so checking only whether the estimate moves with covariate dating would miss it.

**Tools.** (1) a test of whether a late covariate predicts pre-period outcome changes given treatment and an early value; (2) estimates of the shock terms in placebo units; (3) when no early value exists, a sensitivity parameter (correlation between treatment and the window's shock). Simplest fix: date covariates before the earliest placebo window.

**Evidence.** Of 90 recent published studies that adjust for time-varying covariates, 77 date at least one covariate too late (survey measures prevalence, not harm). Telephone-exchange automation study: breakdown value 2.15 with census-year covariates vs 0.70 with 1910 covariates (conclusion holds either way, robustness overstated ~3x). China-shock design: latest placebo slope falls from 0.12 (1975 covariates) to -0.02 (1990 covariates).

**Claude's Take (opinion).** A clean, actionable identification point connecting covariate timing to honest-DiD benchmarks. Caveats: survey counts practice not harm; the R package is not yet released.
