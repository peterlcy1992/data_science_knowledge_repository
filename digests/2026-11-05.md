## 🔎 Deep dive: Do Search-Augmented Recommenders Use the Latest Search Episode?

*arXiv cs.IR (Jiandong Ding, Huawei; WSDM 2027) · personalization-recsys (AI/ML-systems) · AI/ML-systems pick (rotation: 2 of the last 4 deep dives were Core DS, so AI/ML-systems was due) · novelty 4/5 · full text read*

**The problem.** Search-augmented recommenders (SAR) use search behaviour to improve recommendations, but aggregate gains and ablations don't say which search input produced the gain: training supervision, older searches shaping user state, a runtime search field, or the immediately preceding (latest) search.

**The method.** FocalSwap is a fixed-row counterfactual audit. For each recommendation it holds the target, candidates, pre-search history and scorer fixed and changes only the latest search slot or all search inputs, using either neutral masks or matched observed-search replacements as controls. It records rank changes, reciprocal-rank (RR) gains per control, and preference for the true focal search. A planted signal and GenSAR's current-query task confirm the audit detects known dependence. Evidence on KuaiSAR, Qilin, and checkpoints from the released SESRec and UniSAR code.

**Findings.**
- On 66,139 rows across three independently trained UniSAR checkpoints, neutral-mask replacement of all search inputs gives a positive signed contribution; category/profile-matched observed replacements give smaller estimates, with an interval below zero for one checkpoint.
- Paired RR gaps between controls: +2.770e-3 to +6.604e-3, every adjusted interval above zero. Neutral masks change 59.7–61.7% of target ranks vs 44.1–44.8% for matched replacements; the contrast persists across five alternative donor assignments.
- Under the primary controls, positive latest-slot contribution is not established in SESRec or UniSAR.

**Caveats.** Public benchmarks and released implementations only; findings concern the audited datasets, checkpoints and interfaces; "not established" is not "shown to be zero".

**Claude's Take (opinion).** The reference-input point is the takeaway: the same ranking gain can be attributed to search or not depending on the control. Familiar baseline-choice logic from attribution, applied carefully with paired intervals.
