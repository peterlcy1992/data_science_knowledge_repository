# Podcasts

The show is **Data Science in the Wild** — see [`SHOW.md`](SHOW.md) for the
title, tagline, description, and metadata, and [`thumbnail.png`](thumbnail.png)
for the cover art.

Deep-dive audio podcasts generated by the daily refresh (Step 6c of
[`../refresh-playbook.md`](../refresh-playbook.md)) from each day's featured
deep-dive article, via [`notebooklm-py`](https://github.com/teng-lin/notebooklm-py)
and the steering prompt in [`../automation/podcast_prompt.md`](../automation/podcast_prompt.md).

- One file per day: `YYYY-MM-DD-<id>.m4a`, matching that day's deep-dive article.
- Once committed, each file is also reachable on the public Pages site at
  `https://peterlcy1992.github.io/data_science_knowledge_repository/podcasts/<file>.m4a`.
- Generation is **best-effort** — it only runs when NotebookLM is installed and
  authenticated in the run environment (see Step 6c "Prerequisites"). When it
  isn't, the day's digest notes the podcast was skipped.

Each episode has a sidecar `YYYY-MM-DD-<id>.md` (title + description) and a
`YYYY-MM-DD-<id>.cover.png` episode cover, following the show's mono-color
design with the source company's stylized wordmark.
