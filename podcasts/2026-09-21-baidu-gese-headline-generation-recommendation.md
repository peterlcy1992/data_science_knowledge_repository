# Baidu — Why Your AI-Written Headline Sounds the Same to Everyone

Ask an LLM to write the single best headline for a product or a feed item, and it will — but "best on average" quietly means "generic," and the users with more specific tastes get left out. This episode digs into GESE, a system Baidu built to fix that: instead of asking the model for one polished headline, it trains the model to write a whole spread of different headlines, each aimed at a different way someone might be interested in the item, and then hands the job of picking the right one per user to a fast, lightweight selector running in real time. We cover why "mode collapse" is a sneaky failure mode for AI-generated personalization, how reinforcement learning is used to keep the model's outputs diverse instead of narrowing them down, and the production results from a platform with over 100 million daily users — a measurable lift in both clicks and how long people actually stuck around afterward. Source article: "Generate to Explore, Select to Exploit: Aligning LLM-based Headline Generation with Personalized Recommendation" — arXiv (Baidu Inc.), https://arxiv.org/abs/2609.15094 (published 2026-09).
