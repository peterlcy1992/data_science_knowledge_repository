# iFood — Predicting the Discount That Tips a Customer

A deep dive into new work from Prosus and iFood on allocating promotions with a finetuned language model. Instead of forecasting orders per segment, a 4B-parameter model reads a user's history and session context and predicts, in a single token, the smallest discount at which that user would convert. Decoding the token distribution as a conversion-threshold distribution gives a promotion-response curve that is monotone by construction, which feeds a budget-constrained allocator. In a one-month production A/B test on churn reactivation (90/10 split, same budget and allocator), it raised conversion by 1% and cut promotion cost by 6% against the segment-based baseline, while expanding the allocation space from about 50 segments to over 1,000 clusters. Offline against an uplift random forest on randomized data the results are mixed, which the authors flag. Source article: "LCM-Promo: An LLM-Based Uplift Model for Promotion Allocation" — arXiv cs.LG (Prosus / iFood), https://arxiv.org/abs/2610.37570 (published 2026-10).
